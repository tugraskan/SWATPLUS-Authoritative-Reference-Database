# Changelog

All notable changes to this repository and its database releases are recorded
here. Row-level changes are tracked in `metadata/database_changes.csv`; this file
summarizes releases and significant events.

The format follows a lightweight version of Keep a Changelog. Database releases
are versioned `YEAR.MAJOR.MINOR` and tagged `database-v<version>`.

## [2026.2.0]

Authoritative reference database sourced from the official SWAT+ Editor
reference dataset.

### Data

* All core reference files are serialized verbatim from tables in the official
  SWAT+ Editor reference dataset (`swatplus_datasets.sqlite`, v4.0.0, SWAT+
  rev. 62) using SWAT+ Editor's own `fileio` writers, so each file matches, byte
  for byte, what the editor writes into a project. Per-file source table, record
  count, and checksum are recorded in `metadata/bootstrap_sources.json`.
* Seven files that the official dataset does not carry are retained as
  supplemental in `metadata/external_sources.json`: the direct-read databases
  `manure_db.frt`, `manure_om.frt`, `transplant.plt`, `puddle.ops`, and the
  example/unread-by-model files `metals.mtl`, `salt.slt`, `pathogens.pth`.

### Validation & tooling

* `schemas/swatplus-62.0.0.json` — the SWAT+ source-derived description of every
  input database file (fields read, Fortran types, units), generated by
  `swatplus-doc-builder`.
* `scripts/schema_sync.py` — compares the committed data against that schema and
  fails on drift not recorded in `metadata/schema_drift_waivers.json`.
* `scripts/schema_diff.py` — diffs two schema artifacts so adopting a new SWAT+
  release is reviewed as a specific list of format changes.
* `scripts/validate_database_files.py` — file-level validation (field counts,
  data types, header drift, manure cross-references, canonical filenames).
* `scripts/validate_change_log.py` — structural and per-record change-log
  validation.
* `scripts/build_release_package.py` — deterministic, reproducible release ZIP.
* Full unit + integration test suite under `tests/`.

### Known schema-drift (waived, tracked)

* `plants.plt` — the official dataset omits the four SWAT+ 62 carbon-module tail
  columns (`meta_frac`/`str_frac`/`lig_frac`/`pl_class`), which are read
  conditionally and default otherwise. Waived until the editor dataset emits
  them. See `metadata/schema_drift_waivers.json`.
* `pesticide.pes` — `pl_uptake` carries the editor's uniform `0.01` migration
  default rather than curated per-pesticide values (review note).

### Notes

* Source-file header versions are provenance only, not tested compatibility.
* No SQLite database is built or committed. No SWAT+ or SWAT+ Editor code is
  changed.
